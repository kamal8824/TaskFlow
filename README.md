# TaskFlow — MERN Task Manager

A full-stack task management application built using the MERN stack.

## Features

- Create, edit and delete tasks
- Mark tasks as completed or pending
- Search tasks by title
- Filter tasks by status
- Sort tasks by priority
- Set task priorities
- Add due dates
- Track overdue tasks and remaining days
- Responsive design for mobile and desktop

## Tech Stack

- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **API:** REST API

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kamal8824/TaskFlow.git
cd TaskFlow
```

### 2. Install dependencies

```bash
npm install
cd client
npm install
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file in the server folder and add your MongoDB connection string and required server configuration.

### 4. Run the application

Start the backend and frontend in separate terminals using their respective development scripts.
